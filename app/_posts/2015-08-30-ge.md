Amorphous Si area detectors manufactured by GE are currently used at APS and CHESS to acquire
far-field high-energy X-ray diffraction data. The data from such detectors is
stored in multi-frame, 16-bit depth binary images with 8192 bytes of
header data. The data files typically have an extension `.ge2`.
Since ImageMagick is able to deal with raw binary images like
any other image format, it is possible to easily manipulate ge2 files using
the `convert` command-line utility. I have written [a gist](https://gist.github.com/hmparanjape/ef50c999d7fd69c3e996)
that shows some simple ways of processing GE2 images using ImageMagick.
